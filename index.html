FAQ

자주 묻는 질문

마케팅을 하나도 몰라도 쓸 수 있나요?
네, 그게 목적입니다. 업종·상품·타겟 같은 "사장님이 이미 아는 정보"만 입력하면, 심리학 이론과 카피라이팅은 엔진이 알아서 적용합니다. 결과물에는 어떤 심리 원리가 왜 쓰였는지 설명이 함께 제공돼서, 쓰다 보면 자연스럽게 마케팅 감각도 늘어요.
생성된 결과물은 어떻게 사용하나요?
모든 결과물 옆에 복사 버튼이 있습니다. 섹션별로 복사하거나 전체를 한 번에 복사해서 네이버 플레이스, 인스타그램, 광고 관리자 등에 바로 붙여넣으면 됩니다. 생성물은 히스토리에 자동 저장되어 언제든 다시 꺼내 쓸 수 있어요.
카카오톡·구글 간편가입은 어떻게 하나요?
로그인 창에서 카카오 또는 구글 버튼을 누르면 3초 만에 가입됩니다. 이메일로 직접 가입할 수도 있어요. 별도의 서버 없이 운영되는 버전에서는 간편가입이 데모 모드로 동작하며, 관리자가 카카오/구글 개발자 키를 등록하면 실제 소셜 계정 연동으로 전환됩니다.
내 가게 정보는 안전한가요?
입력하신 정보와 생성 결과는 외부 서버가 아닌 사용자 브라우저(localStorage)에만 저장됩니다. 선택적으로 외부 AI(Gemini)를 연동한 경우에만 해당 생성 요청이 외부로 전송되며, 연동은 언제든 해제할 수 있습니다.
어떤 업종에서 쓸 수 있나요?
카페·음식점·뷰티·피트니스·병원·학원·이커머스·숙박·반려동물·부동산/인테리어·프리랜서 등 12개 업종별 심리 데이터가 내장되어 있습니다. 목록에 없는 업종은 "기타"를 선택해도 범용 심리 전략이 적용됩니다.
무료 플랜에도 제한이 있나요?
무료 플랜도 4가지 도구를 모두 사용할 수 있습니다. 생성 횟수(월 30회)와 히스토리 저장 개수(50개)에만 차이가 있어요. 복사 기능은 어떤 플랜에서도 제한이 없습니다.
