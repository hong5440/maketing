# Aside 벤치마킹 실행 브리프

Aside 브라우저가 설치된 컴퓨터에서 실행하기 위한 안내입니다.

## 1. 준비 (Aside가 있는 컴퓨터에서)

```bash
git clone https://github.com/hong5440/maketing.git
cd maketing
git checkout claude/psychology-marketing-homepage-cmuwd4
```

이미 받아 둔 폴더가 있다면 `git pull`만 하면 됩니다.
그 폴더에서 Claude Code를 열고(데스크톱 앱의 로컬 세션 또는 터미널), 아래 지시문을 붙여넣으세요.

## 2. 붙여넣을 지시문

```
# 역할
너는 소상공인 대상 서비스 웹사이트를 다듬는 웹 기획자야.
Aside 브라우저로 비슷한 서비스를 벤치마킹하고 결과를 정리해 줘.

# 시작 전 확인
- Aside가 이 세션에 어떻게 연결되어 있는지(도구·스킬·CLI) 먼저 확인하고 알려 줘.
- 연결이 안 되어 있으면 멈추고 방법을 알려 줘. 명령어를 추측해서 실행하지 마.

# 우리 서비스
- 회사: 고래싸움에 성장하는 새우들 / 서비스: 심리마케팅
- 한 줄: 가게마다 다른 AI, 청년이 맞춰 드립니다
- AI 잘하는 부산 대학생을 교육해 가게와 매칭. 진단 → 처방 → 실행 → 자립
- 현재 홈페이지: 이 폴더의 index.html (구성 요약은 CHANGES-v3.md)

# 할 일 (읽기와 캡처만)
아래 유형별로 2~3곳씩 열어 보고, 각 사이트의
첫 화면 · 서비스 설명 · 신청 흐름 · 가격 표기 · 신뢰 장치(사례, 수치, 후기)를
캡처해서 benchmark/ 폴더에 저장해 줘.
1. 소상공인 마케팅 대행·매칭 서비스 (셀프마케팅 포함)
2. 체험단·리뷰 플랫폼
3. 대학생·청년이 소상공인의 디지털 전환을 돕는 프로그램이나 서비스
4. 가격을 투명하게 공개하는 소상공인 마케팅 서비스
후보 목록은 benchmark/README.md에 있어. 더 적합한 곳이 있으면 바꿔도 돼.

# 결과물
- 캡처 파일명: benchmark/<유형번호>-<사이트명>-<화면>.png
- benchmark/report.md: 사이트마다
  - 주소, 열람 날짜
  - 첫 화면 메시지와 주요 버튼
  - 신청 흐름(몇 단계인지, 무엇을 묻는지)
  - 가격 표기 방식
  - 신뢰 장치
  - "우리가 가져올 점" 한 줄 / "가져오지 않을 점" 한 줄
- 마지막에 "우리 홈페이지에 반영할 제안" 5~10개를 섹션 이름과 함께 정리
  (index.html의 섹션: 히어로, 문제, 작동 방식, 업종별 예시, 진단 도구, 청년 크루,
   가격, 현장 이야기, 함께하는 사람들, FAQ, 신청 양식, 바닥글)

# 반드시 지킬 것
- Aside로 로그인, 회원가입, 양식 제출, 결제, 게시는 하지 마. 읽기와 캡처만 해.
- 문구나 디자인을 그대로 베끼지 마. 구조와 원리만 참고해.
- 보지 않은 내용을 추측해서 적지 마. 확인 못 한 항목은 "확인 못 함"이라고 써.
- 홈페이지 코드(index.html 등)는 내가 승인하기 전에는 수정하지 마.
- 배포하지 마.
```

## 3. 벤치마킹이 끝난 뒤

`benchmark/` 폴더를 커밋해서 올려 주시면(`git add benchmark && git commit && git push`),
그 보고서의 "반영할 제안"을 바탕으로 홈페이지를 한 번 더 다듬을 수 있습니다.
