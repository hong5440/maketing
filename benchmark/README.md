# benchmark/ — 벤치마킹 자료

상태: **Aside 브라우저 실행 대기** (2026-11-10 기준)

## 왜 아직 비어 있나
홈페이지 개편 작업은 클라우드 세션(원격 컨테이너)에서 진행됐고, 그 컨테이너에는
Aside 브라우저와 `aside` CLI/REPL 도구가 설치·연결되어 있지 않습니다.
(확인 항목: 실행 파일, 설정 폴더, MCP 서버, 스킬, 연결 가능한 컴퓨터 폴더 — 모두 없음)

Aside는 사용자의 컴퓨터에서 동작하므로, 벤치마킹은 **Aside가 설치된 컴퓨터의
Claude Code 세션**에서 실행해야 합니다. 실행 방법과 붙여넣을 지시문은
[ASIDE_BRIEF.md](ASIDE_BRIEF.md)에 있습니다.

## 벤치마킹 후보 (웹 검색으로 찾은 이름만 — 아직 열람·검증 전)
| 유형 | 후보 | 비고 |
|---|---|---|
| 1. 대행·매칭 | 셀프마케팅, 크몽 마케터구독, 마케팅천재들(아이보스 대행사 매칭), 숨고 | 셀프마케팅·숨고는 주소 확인 필요 |
| 2. 체험단·리뷰 | 레뷰, 리뷰노트, 디너의여왕 | 광고주용 가격 안내 페이지 위주로 |
| 3. 청년×소상공인 | 카카오페이 사각사각 서포터즈, 서울AI재단 소상공인 매출 증대 프로젝트(청년팀), 제주 대학생 가치가게 디지털 서포터즈 | 모집·운영 구조 위주로 |
| 4. 가격 공개형 | 크몽 마케터구독(구독 요금), 단가표를 공개하는 대행사 1~2곳 | 열람하며 추가 탐색 |

위 목록은 출발점일 뿐이며, 실제 열람 과정에서 더 적합한 곳으로 바꿔도 됩니다.
